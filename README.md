# Meu Futuro Profissional — Isabella Garcia

Portfólio pessoal desenvolvido com HTML, CSS e JavaScript.

## Arquivos
- `index.html` — estrutura e conteúdo do site
- `style.css` — identidade visual, animações e responsividade
- `script.js` — tema claro/escuro, menu mobile, animações de entrada e barra de progresso
- `assets/curriculo-isabella-garcia.pdf` — currículo para download

## Antes de publicar
1. Abra `index.html` e substitua `https://github.com/SEU-USUARIO` pelo endereço real do seu perfil GitHub.
2. Confira se os dados de contato e o currículo continuam atualizados.
3. Como o site ficará público, confira se deseja manter todos os dados pessoais que aparecem no currículo PDF.

## Publicar no GitHub Pages
Crie um repositório público chamado `meu-futuro-profissional`, envie todos os arquivos mantendo a pasta `assets` e ative **Settings → Pages → Deploy from a branch → main → /(root)**.
